Required installations

The page is a local front end. The map is calculated by CCP4, clipped by Coot, and drawn by PyMOL. Python only needs Flask.

  1. CCP4

    Install the CCP4 suite. On this Mac the usual location is /Applications/ccp4-9. The workflows call cif2mtz, refmac5, cad, scaleit, fft, extends, mtzdump, ctruncate, and libcheck after sourcing bin/ccp4.setup-sh.

  2. Coot

    Use the Coot binary shipped with CCP4, typically $CCP4/bin/coot. It runs without a window and writes a map fragment around the residue you choose. The contour slider inside Coot is not the figure; PyMOL draws the surfaces.

  3. PyMOL

    PyMOL must be on PATH. The conda-forge package is enough:

    conda install -c conda-forge pymol

    Headless PyMOL writes the PNG and a .pml script. If ray tracing needs a display, the same scene is rendered again without ray tracing.

  4. This application

    cd web-application
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py

    Then open http://127.0.0.1:5050. Uploaded files and every intermediate — MTZ, logs, the extended map, the site fragment, and the PyMOL script — are saved in the output directory you enter.

  5. Input files

    Coordinates, structure-factor mmCIF, and validation 2Fo−Fc coefficients come from the RCSB PDB. Validation coefficients are also at

    https://files.rcsb.org/pub/pdb/validation_reports/xx/{pdbid}/{pdbid}_validation_2fo-fc_map_coef.cif.gz

    The omit-model workflow expects deposited intensities (I, SIGI) and a FREE flag, which is how 6w1v is distributed. ctruncate converts those intensities to amplitudes.

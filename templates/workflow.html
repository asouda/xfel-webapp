{% if spec.slug == 'fofo' %}

Δρ(r) ∝ Σ (|FLIGHT| − |FDARK|) exp(iφref)

This is the difference-Fourier map between two isomorphous datasets. Positive density means more electrons in the light structure. Negative density means more electrons in the dark structure. A real shift is a negative peak on the old position next to a positive peak on the new one.

How it is calculated

  1. Both structure-factor mmCIF files, and both validation coefficient files, are converted to MTZ with cif2mtz.
  2. refmac5 runs for zero cycles so the amplitudes sit in a consistent MTZ. The deposited atoms are not moved.
  3. cad puts light amplitudes, dark amplitudes, and one phase column in a single file. The default phases are PHWT from the light validation 2Fo−Fc coefficients. You can switch to the dark validation file, or to phases from either zero-cycle REFMAC job.
  4. scaleit scales the light amplitudes onto the dark reference. fft transforms |FLIGHT| − |FDARK| with those phases. The map is then padded around the light model, repeating the unit cell. The sigma on that map stays the value from fft.
  5. Headless Coot clips a sphere around the site. PyMOL draws nested ±nσ isosurfaces, green through blue for positive density and red through magenta for negative density, and writes a PNG plus a .pml script.
{% elif spec.slug == 'refinement' %}

Δρ(r) ∝ Σ (m|Fo| − D|Fc|) exp(iφc)

REFMAC stores that coefficient as DELFWT / PHDELWT. Positive density is present in the observations and missing from the omit model. Negative density is where the model places electrons the data do not support. No second dataset is scaled in.

How it is calculated

  1. An observed mmCIF is converted to MTZ with cif2mtz. An MTZ entered for the reflections is used as that file. ctruncate turns intensities I, SIGI into amplitudes, and cad copies the FREE flag onto those amplitudes. An MTZ that already contains amplitudes skips ctruncate.
  2. The REFMAC refinement section starts off, which runs zero cycles and does not move atoms. Turn it on to set the cycle count, REFI BREF (isotropic, anisotropic, mixed, or overall), and REFI TYPE (restrained or unrestrained). Distance, angle, and dihedral restraints each name their atoms by chain, residue, and atom name. Each group is used only when its switch is on, and those restraints replace the CCP4 monomer library for those atoms. A value written on a line replaces the sigma field for that restraint. When the exclude-restraints switch is on, each line names a chain, a residue anywhere in the model, and the atoms left out of REFMAC restraints. A star means every atom in that residue. Each line is sent as RESTRAINT EXCLUDE RESIDUE. Harmonic restraints hold the atoms listed in that section at their coordinates. When the protein harmonic switch is on, every protein atom in every chain is held at its coordinates in the model, except atoms in the main site and the additional site. The sigma is the value in that field. A custom dictionary applies to the whole model and is used only when its switch is on and the cycle count is greater than zero, and the external restraints are read after it. Harmonic restraints are used only when the cycle count is greater than zero.
  3. fft transforms DELFWT / PHDELWT between the resolution limits above. An optional finer grid resolution asks fft for the sampling of that higher resolution. Reciprocal-space points beyond the coefficients are absent from the MTZ and contribute zero amplitude, so the real-space grid is denser. The map is then padded around the refined model. When the whole-cell grid is too large for fft, that same sum is evaluated on a cube centered on the map center and wide enough for the clip radius. The sigma stays the full-cell value.
  4. Coot clips the site from that difference map. The clip is centered on the site residue, or on a Cartesian point when you set one. PyMOL draws the refined coordinates and the ±nσ surfaces, saves the PNG and the .pml script beside the map, and centers that image on the same point as the clipped map.

The light coordinates stay out of that calculation. In the interactive viewer, Light site draws the same site from that file as ball and stick. Yellow, green, blue, silver, and Name are the color choices. Name colors each atom by its element, the same scheme as the omit model.

{% elif spec.slug == 'reconstruct' %}

Δρ(r) ∝ Σ (m|Fo| − D|Fc|) exp(iφc)

The starting omit model is rebuilt one heavy atom at a time. Each iteration refines the current omit model and calculates its mFo−DFc map. The highest peak of the clipped map is matched to the nearest eligible heavy atom in the reference model, and that atom’s PDB record is added to the refined coordinates at the Cartesian position of the peak. That structure is the omit model of the next iteration. A peak whose voxel density is below the density cutoff is treated as noise: no atom is added, and the reconstruction stops. By default an atom already in the omit model is not eligible. The form can include every heavy atom in the reference model instead. When that choice selects an atom whose identity is already in the working model, the existing record is removed and the reference record is written at the peak, which moves that atom. Hydrogens are not candidates.

How it is calculated

  1. The omit-map workflow refines the current omit model and calculates its clipped mFo−DFc map. The REFMAC refinement section starts off, which runs zero cycles and leaves the heavy atoms where they are. Turn it on to set the REFMAC protocol and two cycle counts. The initial omit model, before any atom is added, uses its own count. Each later reconstruction step, including the residual map of the finished model, uses the other count. When the exclude-restraints switch is on, each line names a chain, a residue, and the atoms left out of REFMAC restraints. A star means every atom in that residue. Each line is sent as RESTRAINT EXCLUDE RESIDUE. The refined coordinates are saved as the omit-model name followed by _refined_stepNN.pdb. When Copy LINK records before each refinement is on, which is the default, the LINK records from the starting omit model replace the LINK records in each step’s omit model, including the initial omit model, before that refinement. A repeated record is written once. An optional file replaces those records in every omit model, including the initial one. The records include the ones that name atoms added in earlier steps. REFMAC leaves a LINK record out of the coordinates it writes while either atom is still missing, so the chosen records replace the LINK records again at the next step. A custom dictionary is read only when its switch is on and the cycle count is greater than zero. When the harmonic switch is on, each atom added in an earlier iteration is held at the coordinates written into the omit model. The default sigma is 0.1 Å. Distance, angle, and dihedral restraints name each atom by chain, residue, and atom name. When the protein harmonic switch is on, every protein atom in every chain is held at its coordinates in the model, except atoms in the main site and the additional site. Those restraints are used only when the cycle count is greater than zero.
  2. When the map-check interval is a positive integer, the calculation pauses after that many iterations. The 3D viewer shows the site from the refined omit model, named with _refined_stepNN.pdb, and that iteration’s difference map. PyMOL writes a script in the iteration folder at every step, and it runs that script to save a PNG only for a step that pauses here. When a highest-density voxel was found, a small magenta octahedron marks its coordinates. A note in the lower-left corner of the viewer gives the step, the closest reference atom, and its distance from that voxel. Continue iterations resumes the search. An interval of 0 shows only the finished model and its residual map, and does not run PyMOL.
  3. The peak is the strongest voxel that is a local maximum inside a cubic neighborhood of the map calculated after REFMAC. When the spline maximum is on, the point moves to the spline maximum inside that neighborhood. The default neighborhood is 3 and the default spline order is 3.
  4. Density profiles through that point, from −2 Å to +2 Å, are written in the iteration directory. The offset is the distance in Ångstroms along the line. The columns are the Cartesian x, y, and z axes, the six face diagonals of the cube, and the four body diagonals. If that voxel’s density is below the density cutoff, the peak is treated as noise and the reconstruction stops without adding an atom. Otherwise the nearest eligible heavy atom in the reference model is identified. A distance beyond 1 Å is a warning. A distance beyond 3 Å stops the reconstruction without adding that atom.
  5. The reference atom’s PDB record is inserted into the refined coordinates, at the peak. The atom name, residue, and chain stay those of the reference atom. When every heavy atom is eligible and that identity is already in the working model, the existing record is removed first, so the atom moves to the peak. The density-section file then says that the position of that existing atom has been adjusted. The iteration log and the Note column record how far that atom moved. Distance to reference remains the distance from the peak to the reference coordinates. Otherwise the density-section file says the atom was added. The result is saved as the omit-model name followed by _refined_added_, the atom name, and _stepNN.pdb. The next iteration refines that file. The loop repeats until the requested number of atoms has been added, or until no atom can be added. The last iteration refines the model and does not insert an atom. The viewer shows those refined coordinates and the residual map. They are saved as the omit-model name followed by _reconstructed_final.pdb. A table under the viewer lists each step, the final REFMAC R-factor and R-free, the atom added at the peak, its coordinates, and its distance to the reference atom. When the run finishes, that table is written in the output directory as the omit-model name followed by _reconstruction.csv and _reconstruction.xlsx. Bonds are drawn wherever two displayed atoms are close enough to be bonded.

Logs, maps, and the density profiles of each iteration are written in r-iteration-01, r-iteration-02, and so on, inside the output directory. PDB, CCP4, map, and density-section files in those directories end in _step01, _step02, and so on. The PyMOL script is written for every iteration. A PNG with the same step suffix is written only when that iteration pauses for a map check. Reference site in the viewer draws the reference model in ball and stick.

{% else %}

ρ(r) ∝ Σ FWT exp(−ΔB (sinθ/λ)2) exp(iφWT)

This is not a difference map. FWT is already the weighted 2m|Fo| − D|Fc| amplitude from the wwPDB validation file, and PHWT is the model phase. Mesh that covers an atom is accounted-for density. A gap on an atom, or a blob with no atom, is the usual hint that the model and the data disagree. Levels of 1–2σ are the normal view; 3–5σ is for difference maps and will often leave this mesh empty.

How it is calculated

  1. The structure-factor mmCIF and the validation coefficient mmCIF are converted to MTZ.
  2. fft sharpens FWT with SCALE F1 1 ΔB and transforms it with PHWT. Negative ΔB boosts the high-resolution terms. The default −40 Å2 is a sharpening of 40 Å2. ΔB = 0 leaves FWT unchanged.
  3. The map is padded around the model by repeating the unit cell. The sigma stays the value from fft. Coot exports a normal map fragment, not a difference map.
  4. PyMOL superimposes the site and neighbouring residues and draws one isosurface at each requested σ. The scene script is saved next to the extended map and the PNG.

## CSV contents

Each CSV provides one line per omitted atom with record type, original PDB atom serial number, chain, residue number and name, atom name, alternate-location label, element, and Cartesian coordinates (`x_A`, `y_A`, `z_A`, in Å). To inspect a specific omitted atom or retrieve its original coordinates, use the matching CSV.
